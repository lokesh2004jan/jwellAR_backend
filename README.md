# 💎 JewelAR – AI Jewelry Try-On System

## 🚀 Overview
JewelAR is an AI-powered AR application that allows users to virtually try jewelry and receive personalized recommendations.

---

## 🧠 Features
- Real-time AR jewelry try-on
- Backend APIs using Spring Boot
- AWS cloud integration (EC2, RDS, S3)
- Scalable image storage using S3
- Secure data handling using MySQL (RDS)

---

## 🏗️ Architecture

Frontend → Backend (Spring Boot on EC2)  
              ↓  
        RDS (MySQL) + S3 (Images)

---

## ☁️ Cloud Stack
- AWS EC2 – Backend deployment  
- AWS RDS – Database  
- AWS S3 – Image storage  

---

## 🔧 Tech Stack
- Java (Spring Boot)
- MySQL (RDS)
- AWS (EC2, S3)
- Docker
- OpenCV
